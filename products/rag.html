How it works

From files to cited answers.

01 · INGEST

Upload documents

PDF, DOCX, TXT, MD, HTML, CSV, JSON — 50+ file types, processed in the background with progress tracking.

02 · CHUNK

Smart chunking

Adaptive chunk size from 100 to 2000 tokens with configurable overlap, plus filename, page and type metadata.

03 · RETRIEVE

Semantic search

ChromaDB-powered retrieval with adjustable parameters, isolated per project.

04 · ANSWER

Any LLM provider

Pick the model per conversation. Answers stream over Server-Sent Events.

Token counting runs in real time so you can estimate cost before you commit to a model.
