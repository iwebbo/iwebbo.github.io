How it works

Four steps from file to answer.

01 · UPLOAD

Any common format

PDF, Word, Excel, Markdown, code (Python, Java, JS) and YAML.

02 · EMBED

Automatic vectorization

Embeddings generated with Sentence Transformers.

03 · INDEX

OpenSearch k-NN

A vector index on OpenSearch 3.x, using FAISS as the k-NN engine.

04 · SEARCH

Hybrid retrieval

Semantic and keyword search combined, ready for RAG on top of the vectorized content.

Everything is available through the web UI and a documented REST API, with curl examples for each endpoint.
